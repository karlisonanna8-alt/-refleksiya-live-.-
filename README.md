# Чемпионат рефлексии — голосование с телефонов
Node ≥18, без зависимостей. Запуск: `node server.js` (PORT из окружения, по умолчанию 3000).
- Общий экран: `/` — QR, код комнаты, живые счётчики, управление этапами.
- Телефон ученика: `/<КОД>` (4 символа).
- Данные: в памяти + `data/rooms.json` (DATA_FILE). Комнаты удаляются через 48 ч без активности.
Деплой: любой хостинг Node (Render — render.yaml, Railway, Fly, VPS). Тест: `node test.js` при запущенном сервере.
